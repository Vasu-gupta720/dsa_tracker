DSA Tracker
===========

A small React + Vite app to track DSA practice problems.

Getting Started
---------------

Prerequisites
- Node.js (16+)
- npm (or yarn)

Install

```bash
npm install
```

Run (development)

```bash
npm run dev
# then open the URL shown by Vite (usually http://localhost:5173)
```

Build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

Project Structure
- `index.html` - app entry
- `src/DSATracker.jsx` - main component
- `src/main.jsx` - app bootstrap
- `style.css` - styles
